# 📚 Student Attendance System

Sistem Pencatatan Absensi Siswa berbasis web yang dirancang untuk mempermudah pengelolaan dan pemantauan kehadiran siswa secara efisien dan responsif.

---

## 🚀 Fitur Utama

- 📝 **Pencatatan Absensi:** Mengisi kehadiran siswa (Hadir, Izin, Sakit, Alpa) secara real-time.
- 📊 **Rekapitulasi Data:** Memantau riwayat dan statistik kehadiran siswa.
- 📱 **Desain Responsif:** Tampilan yang nyaman diakses melalui perangkat *desktop* maupun *mobile*.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend:** HTML5, JavaScript (ES6+)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Build Tool / Processing:** PostCSS, Autoprefixer
- **Version Control:** Git & GitHub

---

## 💻 Cara Menjalankan Proyek di Lokal

Jika kamu ingin menjalankan proyek ini di komputer lokal, ikuti langkah-langkah berikut:

### 1. Prasyarat
Pastikan kamu sudah menginstal **[Node.js](https://nodejs.org/)** di komputermu.

### 2. Clone Repositori
```bash
git clone https://github.com/USERNAME/student-attendance.git
cd student-attendance
```
*(Ganti `USERNAME` dengan username GitHub kamu)*

### 3. Install Dependensi
Jalankan perintah ini untuk menginstal semua *library* yang dibutuhkan (termasuk Tailwind CSS):
```bash
npm install
```

### 4. Jalankan Proyek
Jalankan perintah *build* atau *development server*:
```bash
npm run dev
```
